УСТОЁБ — ЛОИҲАИ ANDROID (APK)

1) Дар GitHub репозиторийи нав созед, масалан: Ustoyob (Public).
2) Ҳамаи файлҳои дохили ҳамин папкаро (на худи папкаро!) бо «Add file → Upload files» бор кунед.
   Папкаи .github ҳатман бояд бор шавад.
3) Settings → Actions → General → Workflow permissions → Read and write permissions → Save.
4) Вкладкаи Actions: «Build APK» 3–6 дақиқа. ✅ = тайёр.
5) Линки APK:
   https://github.com/<НОМИ_ШУМО>/Ustoyob/releases/latest/download/Ustoyob.apk
